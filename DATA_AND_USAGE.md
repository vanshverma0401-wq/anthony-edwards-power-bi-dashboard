# Data attribution and usage boundary

## Source attribution

The original project report identifies the following sources:

- Basketball-Reference player game-log pages for Anthony Edwards and the five comparison players.
- Basketball-Reference and NBA.com team game logs or standings for Minnesota Timberwolves context.

The academic workbooks did not preserve a complete row-level source URL ledger. The public case study therefore names the providers, links to their current terms, and does not redistribute the raw tables.

Relevant provider pages and policies:

- Basketball-Reference: https://www.basketball-reference.com/
- Sports Reference terms: https://www.sports-reference.com/termsofuse.html
- Sports Reference sharing guidance: https://www.sports-reference.com/sharing.html
- NBA.com terms, including the NBA Statistics section: https://www.nba.com/termsofuse

## Public package decision

The public candidate contains team-authored dashboard screenshots, an original explanatory narrative, source fingerprints, aggregate checks and selected technical metadata. It excludes:

- Source Excel workbooks
- The PBIX and its embedded data model
- Course proposal and final report
- Instructor material, grading information, or feedback
- NBA, team, or provider logos

This boundary is intended to respect provider restrictions on comprehensive statistical databases and to keep the public package non-commercial and attribution-forward.
